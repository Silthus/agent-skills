# Credits

`pr-description` is a rewrite of [Matt Pocock](https://github.com/mattpocock)'s [`pr`](https://github.com/mattpocock/skills) skill (MIT). It keeps that skill's goal, a PR body that is fast to review, and adds a problem-first structure, the `merge-risk` callout, and UI evidence rules. Its name differs, so both skills can be installed side by side.

The menu of implementation views (flow diagrams, pseudocode, diff sketches) and its placement guidance come from [Dex Horthy](https://github.com/dexhorthy)'s [`show-me`](https://github.com/humanlayer/humanlayer) skill, aimed at a diff instead of a live conversation. `pr-description` does not depend on `show-me` as a skill (a hard dependency would break standalone installs), so the content is copied in rather than pointed at; this file is the attribution a dependency would otherwise have carried.
